# Bundled garage gallery

The files `public/images/garages/garage-01.png` through `garage-10.png` are original AI-generated, photographic-style illustrations created for this GarageShare demonstration. They depict fictional parking spaces and are not evidence of real properties, ownership, dimensions, safety, or availability. The gallery uses the bundled WebP images; a neutral garage icon is used for pending host photos.

All ten images are bundled with this project. No third-party image server is required to display the demonstration gallery. Replace them with accurate, authorized photographs before publishing real garage listings.

Fonts: Manrope and DM Sans, bundled with their OFL license texts in `public/vendor/fonts/`. Leaflet's license is included in `public/vendor/leaflet/LICENSE`.

Responsive `.webp` (960px) and `-480.webp` derivatives are encoded from these originals for faster delivery; they depict the same fictional scenes. This Hostinger edition bundles WebP variants and SVG fallbacks; large original PNGs remain in the source edition and are omitted here.
