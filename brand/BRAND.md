# GarageShare visual identity

Selected app name: **GarageShare**. Tagline: **A place for your car.**

`garageshare-mark.svg` is the editable original mark. `garageshare-icon-1024.png` is a raster export. The Android adaptive icon uses the same visual idea: an open garage with a location point beneath it. Leave at least one fifth of the icon width clear around it.

| Token | Colour | Use |
| --- | --- | --- |
| Tangerine | `#ED5835` | Logo, booking actions, selected navigation |
| Warm paper | `#FBF8F2` | Main background |
| Forest ink | `#23352E` | Headings and map price pins |
| Soft sage | `#E5EDE1` | Secondary surfaces and notices |
| Quiet grey | `#737D74` | Supporting text |

Typography: Manrope for the wordmark and section headings; DM Sans for the upright discovery headline, body and controls. Both fonts are bundled with their license files under `web/assets/vendor/fonts`.

Voice: short, useful and calm. Show the complete price and period together. Use “sample” for preview data, “in review” for an unpublished listing, and “confirmed” only when a reservation actually blocks availability. Do not add verification, insurance or rating badges without the corresponding evidence and functionality.

The proposed name has not been checked for trademark or domain availability.

Arabic uses the bundled Cairo font and a right-to-left interface. The GarageShare wordmark remains Latin in every language.
